# stampedestamps.store

The StampedeUSA website: five hand-written pages that send shoppers to the eBay store
(https://www.ebay.com/str/stampedeusa). Hosted free on GitHub Pages with free https
(Douglas, 2026-10-11, chosen over GoDaddy Website Builder 7.0, which has no free certificate).

- Look: matches Stamp Stories (https://stampedestamps.github.io/stampede-stories/).
- Pages: `index.html` (Home, built), `shop.html`, `sale.html`, `about.html`, `feedback.html` (to build).
- Photos: `images/`, web-sized copies (long side 1600 px) of the listing scans under
  `R:\- CENTER for CLAUDE\EBAY\Ebay LISTINGS by SKU #`. `images/hero.jpg` is still to come.
- Font: League Gothic in `fonts/`, SIL Open Font License (`fonts/OFL.txt`).
- `CNAME` holds the custom domain. No prices on any page: eBay shows the live price.
